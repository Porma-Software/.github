# .github

Organization-wide defaults for Porma Software repositories.

- `profile/README.md` — organization profile shown on the org page (only when this repo is public).
- `CONTRIBUTING.md`, `SECURITY.md` — default community health files inherited by every repo without its own.
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` — default issue and PR templates.
- `brand/` — logo and wordmark (SVG, monochrome, `currentColor`) plus a PNG avatar.

Repos that need their own versions simply add the file locally; GitHub prefers the local copy.
