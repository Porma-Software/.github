# Security Policy

## Supported versions

Only the `main` branch of each repository receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting on the affected repository ("Security" tab, "Report a vulnerability"). If that is not enabled for the repository, open a blank issue titled `security: contact request` without details and a private channel will be arranged.

You will get an acknowledgement within 5 working days. Fixes are published as regular releases; credit is given if you want it.
